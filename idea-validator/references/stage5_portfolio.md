# 5단계 — 포트폴리오 패턴 리뷰 (기각 로그 5개 쌓일 때마다)

> 이 로그는 **개인 베팅 모드** 전용이다. 회사 신사업의 기각 로그는 회사 저장소에 남긴다. 회사 신사업에서 같은 사망 벽이 반복되면, 회사명·수치를 뺀 패턴만 게이트 개정 후보로 올린다.

1. 기각 로그를 모아 **반복되는 사망 벽**을 센다. 3회 이상 같은 벽 → 게이트 최상단 승격 (G1이 그렇게 생겼다).
2. 사용자가 **어느 필드에서 반복 베팅**하는지 vs **어디서 살아남는지** 대조 (예: "감성 소비재는 전부 기각, 내 경력 도메인 것만 생존").
3. 살아남은 아이템의 공통 구조를 추출해 **다음 아이디어 생성의 제약조건**으로 쓴다.
4. 결과를 gates.md에 반영하고 버전을 올린다. 승격 이력을 남긴다.
