# 1단계 — 리서치 (전제 검증 + 트렌드 + 지형)

**목적:** 아이디어의 전제와 시장을 사실로 고정. 여기서 틀리면 뒤가 전부 헛수고.

## 입력
아이디어 한 줄 (+ 사용자가 믿는 전제가 있으면 그것)

## 할 일

### 1. 전제 검증
- 아이디어에 깔린 가정을 명시하고 데이터로 확인 (예: "카메라 앱은 1인이 돈 번다").
- **생존자 편향 / 반쪽 진실 / 거짓** 판정. 중앙값과 상위 사례를 분리한다. 히트 몇 개로 카테고리를 판단하지 않는다.

### 2. 글로벌 트렌드·아날로그 (3개 렌즈, 각 1~2회 검색으로 제한)
> 트렌드 리서치는 길어지면 회피가 된다. 렌즈당 판정 한 줄을 강제한다.

- **렌즈 A · 글로벌 아날로그:** 해외에 이미 **확립된 카테고리**가 있는가? 있다면 누가, 어떤 모델로, 얼마에.
  → "확립 카테고리의 한국 공백"은 가장 강한 기회 패턴 (예: 해외엔 있는 B2B 데이터 서비스가 국내엔 없음).
  → 반대로 해외에서도 실패한 카테고리면 그 사망 원인을 가져온다.
- **렌즈 B · 카테고리 모멘텀:** 지금 성장/정체/쇠퇴 중인가? 최근 12개월 펀딩·런칭·종료 신호.
- **렌즈 C · 인프라 변화:** 최근 **API·플랫폼 정책·규제·비용**이 문을 열었나 닫았나?
  (예: 플랫폼 API 신설·종료, 보안 심사 비용 변화, 공공데이터 공개 범위 확대)
  → 인프라 변화가 만든 "새로 열린 창"이 있으면 그것이 타이밍 근거.

**출력:** 렌즈별 판정 — `기회창 열림 / 닫힘 / 무관` + 한 줄 근거.

### 3. 경쟁 지형
- 기존 플레이어, 가격 앵커, **무료 공급의 두께**, **인간 전문가 프리미엄층** 존재 여부.
- 같은 데이터/니즈를 **다른 타겟**으로 푸는 인접 플레이어까지 (예: 같은 공공데이터를 한 곳은 구직자에게, 다른 곳은 투자자에게 판다).

### 4. G1 사전조사
- 핵심 데이터의 API/라이선스 존재 + **상업 이용 조건을 원문으로** 확인.
- 함정 체크: 비상업 이용 제한 / 제한 범위 권한 + 보안 심사 / 필요한 엔드포인트 부재(예: 트렌딩·검색) / 관계 그래프 접근 불가.

### 5. 규제 사전조사
OAuth 범위, 플랫폼 정책, 개인정보(제3자 정보주체 동의 여부).

## 규칙
- 검색 없이 단정 금지. 주장마다 출처.
- 인용 15단어 미만, 출처당 1회. 나머지는 요약.
- 모르면 "확인 못 함". 채우지 않는다.

## 출력 → 핸드오프 (references/handoff.md 포맷)
- 전제 판정 + 근거 1줄
- 트렌드 렌즈 A/B/C 판정
- 경쟁 표: 플레이어 | 타겟 | 가격 | 무료층
- 데이터 접근 사실표: 데이터 | API | 상업이용 | 제공단위(스냅샷/델타) | 래그
- 규제 플래그
