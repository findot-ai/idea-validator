# idea-validator

새 사업·제품 아이디어를 "될까?"가 아니라 **"어느 벽에서 죽는가"** 로 검증하는 Claude 스킬입니다. 편들지 않습니다. 벽을 먼저 찾아 싸게 죽이고, 살아남은 것에만 시간을 씁니다.

*A Claude skill that stress-tests business ideas through ordered gates, cheap experiments, and market-based payment evidence (Korean).*

## 무엇을 하나
| 단계 | 하는 일 |
|---|---|
| 1. 리서치 | 아이디어에 깔린 전제를 데이터로 확인, 해외 아날로그·모멘텀·인프라 변화, 경쟁 지형 |
| 2. 구조화 | 게이트 G1~G5를 순서대로 통과(앞에서 막히면 바로 기각), 지불 5요인, make-or-break 하나로 압축 |
| 3. 검증 | 예측을 먼저 적고, 지을 것 없이 싼 실험으로 실측, 예측 갱신 |
| 4. 사업성 | 실제 지불 증거, 공급 3층(무료·중간·전문가), 앱 없이 먼저 파는 길 |
| 5. 포트폴리오 | 기각 로그가 쌓이면 반복되는 벽을 게이트로 올린다 |

- 게이트: 합법 데이터 접근 → 축적 부담 → 무료 LLM 대체 → 해자-자산 일치 → 상품화 유형
- 모드 둘: **개인 베팅**(사이드 프로젝트) · **회사 신사업**(기존 사용자·데이터·채널이 있을 때)
- 판정: 통과 · 조건부 · 기각. 기각은 실패가 아니라 검증 완료입니다. 어느 벽에서 죽었는지 남깁니다.

## 이렇게 말하면 씁니다
"이거 어때", "사업성 봐줘", "검증해줘", "신사업 후보 비교", "/validate" — 그리고 "좋은 아이디어지?", "잘될 이유만 정리해줘"처럼 편들어 달라고 할 때도 씁니다.

## 설치
- **claude.ai**: [Releases](https://github.com/findot-ai/idea-validator/releases)에서 zip을 받아 스킬로 업로드
- **Claude Code**: `idea-validator/` 폴더를 `~/.claude/skills/`에 복사

## 테스트
`idea-validator/evals/`에 케이스 3개(정상 · 함정 · 경계)가 있습니다. 스킬 폴더에서 `claude plugin eval .`로 돌립니다. 실제 과금되는 실행입니다.

## 원칙
- 예시와 테스트 케이스의 아이디어는 모두 가상입니다.
- 시장·API·규제는 검색 근거 없이 단정하지 않습니다. 숫자를 예쁘게 만들지 않습니다.
- 최종 go 판정은 사용자가 합니다.
